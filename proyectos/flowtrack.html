FlowTrack

Plataforma colaborativa de gestión de proyectos con tableros kanban, seguimiento de tiempo y reportes en tiempo real para equipos distribuidos.

Problema

Los equipos remotos carecían de visibilidad sobre el progreso diario. Las herramientas existentes eran lentas o demasiado complejas para equipos pequeños, lo que obligaba a combinar varias aplicaciones inconexas (un chat, un gestor de tareas, una hoja de cálculo) generando fricción y pérdida de contexto.

Qué se construyó

Dashboard en tiempo real con drag & drop, notificaciones push, integración con GitHub y generación automática de sprints basada en carga de trabajo. Se diseñó una API REST con WebSockets para sincronización instantánea entre miembros del equipo, un sistema de roles con permisos granular, y un motor de reportes que exporta métricas de productividad en PDF y CSV.

Stack tecnológico

React Node.js PostgreSQL WebSocket Docker Redis Tailwind CSS
